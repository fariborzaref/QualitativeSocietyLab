# Qualitative Society Lab
**Dr. Fariborz Aref — Dual PhD | Sociologist & Methodologist**

Exploring meaning, identity, and power through qualitative inquiry.  
This repository contains structured frameworks, datasets, and guides for advanced qualitative research in sociology and community development.

---

## 🧩 Core Modules

### 1️⃣ Focus Groups
- NVivo project files for group discussion coding  
- PDF codebooks and theme matrices  
- Framework for analyzing consensus and conflict in group settings  

📂 [Open Folder](./Focus_Groups)

---

### 2️⃣ In-Depth Interviews
- Interview protocol design (semi-structured)  
- Thematic analysis templates and example transcripts  
- Workflow for integrating NVivo + Excel qualitative summaries  

📂 [Open Folder](./In_Depth_Interviews)

---

### 3️⃣ Institutional Discourse Analysis
- Text corpus of institutional statements  
- Step-by-step manual for discourse coding  
- Outputs compatible with **Text_Network** models (for mixed-methods integration)

📂 [Open Folder](./Institutional_Discourse)

---

## 🧠 Purpose
The **Qualitative Society Lab** unites the interpretive tradition with computational thinking.  
It complements the [Quantitative Society Lab](https://github.com/fariborzaref/QuantitativeSocietyLab) by focusing on *voice*, *context*, and *meaning* rather than only numbers.
